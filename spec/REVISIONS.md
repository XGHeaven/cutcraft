# Spec 修订记录

当前标识：**`0.1.0-r1`**。

## 标识规则

`<协议版本>-r<修订序号>` 标识该协议下的规范与 Schema 集合修订，用于文档引用和变更追踪。首个公开基线记为 `0.1.0-r0`；后续兼容扩展或规范修订递增修订序号。

- 工程 `specVersion` 和事件 `eventVersion` 仍为 `0.1.0`，不使用 `0.1.0-r1`，也不增加持久化修订字段。
- Schema 的 `$id` / `$ref` / 工程 `$schema` URI 保持不变，继续离线加载。
- 效果等组件以自身的类型和 `version` 定义语义；后端能力以 `capabilities` 为准。修订序号不用于推断某个实现能否渲染。
- 不得用修订号原地改变已有数据的含义。破坏兼容性的工程协议变化仍需新协议版本和独立 Schema；已有组件的语义变化仍需新组件版本。
- 修订不表示 CLI 发版，不迁移或改写用户工程、ID、revision、事件及历史哈希。内部 0.3/0.4/0.5 继续按各自归档契约处理。

## 0.1.0-r1 — 高斯模糊扩展

修订标识登记日期：2026-10-28。

- 定义 `builtin.gaussian-blur` **1.0.0**，包含 sigma 的像素单位、默认值、范围、离散高斯核、边界钳位、线性光和预乘 alpha 规则，见 [EFFECTS.md](EFFECTS.md)。
- 注册可动画的 `sigma`，复用 owner 时钟和通用数值动画，见 [ANIMATION.md](ANIMATION.md)。
- 在现行 [effect Schema](schemas/effect.schema.json) 中验证静态/动画参数，并提供[可校验示例](examples/blur.cutcraft.json)。其他已有效果语义不变。
- 此效果仅支持公开 Spec 0.1.0；内部归档版本不增加该能力，不自动迁移。

同次实现中的单帧和区间预览属于应用能力，不新增工程协议字段；使用方式见 [CLI 预览](../docs/preview.md)。

## 0.1.0-r0 — 首个公开基线

回溯命名高斯模糊扩展前的公开 0.1.0 基线，涵盖工程模型、精确时间、操作/历史、调色与 LUT、动画、转场、时间重映射和图片序列。此命名不修改既有发布物或归档文件。
